يشتغل على أندرويد 10 أو أحدث.

## تحويله لملف APK عن طريق GitHub (مجانًا ومن غير تسطيب أي برامج)
1. اعمل حساب على github.com.
2. دوس New repository، سمّيه NewHires، ودوس Create repository.
3. دوس على "uploading an existing file"، واسحب كل محتويات الفولدر ده
   (بما فيها فولدر .github) وحطها في الصفحة، ودوس Commit changes.
4. روح على تبويب Actions. لو طلب تفعيل، فعّله. هتلاقي بناء شغال، استنى لحد ما تظهر علامة صح خضرا (حوالي 5 دقايق).
   لو ما بدأش لوحده: اختار Build APK ودوس Run workflow.
5. ادخل على البناء، وتحت Artifacts نزّل NewHires-APK، وفك الضغط هتلاقي app-debug.apk.
6. ابعت الملف للموبايل وسطّبه (هيطلب منك تسمح بتسطيب تطبيقات من مصادر غير معروفة).

## لو عندك مبرمج
يفتح الفولدر في Android Studio ويشغّله على الموبايل مباشرة.
